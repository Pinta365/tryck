# KaTeX

`katex.min.js` is [KaTeX](https://katex.org) 0.18.11 (`dist/katex.min.js` from the npm package `katex@0.18.11`, sha512 integrity `yvyz/2VMKqoho/35Hat5w37wIEdWJ5ElVMidTAlWrxr5uW4aBGsEpveTmKh18/zw08v/7lGswCPon4OhqmqrTA==`), MIT licensed; see `LICENSE`. The math plugin embeds it and runs it in goja to render formulas to MathML at build time.

To update, download the package's tarball from the npm registry, check its integrity against the registry, and replace both files. Update the version here and in `katexVersion` in `math.go`.
