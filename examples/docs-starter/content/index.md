# Welcome

This site is built with [tryck](https://github.com/Pinta365/tryck), a single-binary static site generator for documentation.

- Read [Installation](01-getting-started/01-installation.md) to get going.
- See [Writing pages](01-getting-started/02-writing-pages.md) for Markdown, directives and links.

:::tip[Live reload]
Run `tryck dev` and edit any file in `content/`. The browser reloads on save, and build errors show up as an overlay.
:::
