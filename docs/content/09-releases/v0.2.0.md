`pkg/tryck` lets a Go program run the whole tryck command line with extra plugins compiled in: `func main() { tryck.Main(&myplugin.Plugin{}) }`. Plugins can declare their config keys so typos warn, and two plugins with the same name are an error. See [Go plugins](../05-extending/05-go-plugins/_index.md).
