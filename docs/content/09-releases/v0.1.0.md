The first release of tryck: Markdown with `:::` directives, clear `file:line` diagnostics, link and anchor checking, clean URLs, a sitemap, a search index and redirects, themes, mermaid diagrams, a dev server with live reload, and `tryck init` with a GitHub Pages workflow.
