- **Fewer reloads in `tryck dev` on Windows.** Windows reports a folder as changed whenever a file in it is saved. The dev server took that as a change to the site, so editor swap files, which it otherwise ignores, rebuilt the site and reloaded the browser every few seconds while you typed. Folder changes are now ignored, since the file inside has its own change; adding, removing or renaming a folder still rebuilds.

Upgrading: nothing to change.
