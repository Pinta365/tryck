**Versioned docs.** Keep the docs of older releases online next to the current ones. `content/` stays the current version at the site root; older versions are snapshots in `versions/<name>/`, served under `/<name>/`. Each version has its own navigation and search, links stay inside their version, and a version picker and a banner on old pages help readers find the current docs. Older versions are kept out of search engines. `tryck snapshot <name>` freezes the current content as a new version. See [Versioned docs](../02-writing/06-versioned-docs.md).

**Feeds.** The new `feed` plugin writes an Atom or RSS feed of the pages that have a `date`, for blogs, release notes and changelogs. Sites without dated pages get no feed. See [feed](../05-extending/01-built-in-plugins.md#feed).

Upgrading: nothing to change. Template authors get `.Version` and `.Versions`; plugins see a `Version` field on pages.
