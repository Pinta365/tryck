`tryck build --strict` treats warnings like errors: broken anchors, unknown config keys and other warnings fail the build, nothing is written, and the exit code is `1`. Use it in CI for pull requests. See [Command line](../03-configuration/02-command-line.md#build) and [Checking pull requests](../06-deploying.md#checking-pull-requests).
