The [llms.txt proposal](https://llmstxt.org) reached version 2 in August 2026. The `llmsTxt` plugin now follows it:

- **Markdown copies at the page's URL.** A page's copy is now at its own URL with `index.md` added: `/guide/setup/` has `/guide/setup/index.md`. An agent can find the copy from any page URL without reading `llms.txt` first.
- **Link relations.** Every page links its Markdown copy with `<link rel="alternate" type="text/markdown">` and `llms.txt` with `<link rel="describedby">`, so an agent that lands on a page finds both.

See [llmsTxt](../05-extending/01-built-in-plugins.md#llmstxt) for the details.

Upgrading: the Markdown copies have moved, from `/guide/setup.md` to `/guide/setup/index.md`. `llms.txt` and the links between copies use the new URLs, so nothing in your site needs to change, but links you shared to the old copies stop working. The home page's copy stays at `/index.md`.
