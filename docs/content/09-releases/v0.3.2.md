`href` and `src` attributes on custom directives are now links: a relative path to a Markdown file or an asset is rewritten to its URL, the base path is added, and broken links fail the build like broken Markdown links. A card can link with `href="../guide/setup.md"`. See [Custom directives](../05-extending/02-custom-directives.md#links-in-attributes).

The search box's logic is now tested in CI.

Upgrading: directive templates should output `.Attrs.href` as it is. A template that wraps it in `relURL` now gets the base path twice; remove the `relURL`.
