- **llms.txt.** A new built-in plugin, `llmsTxt`, writes [`/llms.txt`](https://llmstxt.org): a Markdown index of the site that AI assistants and coding agents can read, with every page's title and description, grouped like the navigation.
- **Markdown copies.** Every page is also written as Markdown next to its URL, `/guide/setup/` as `/guide/setup.md`, with links made absolute so each copy stands on its own.
- **llms-full.txt.** With `full: true`, every page in one file. It is off by default because it can be large.

See [llmsTxt](../05-extending/01-built-in-plugins.md#llmstxt) for the options and exactly what the files contain. This site has them: [llms.txt](/llms.txt).

Upgrading: the plugin is on by default, so builds now write `llms.txt` and a `.md` file per page. Set `plugins.llmsTxt.enabled: false` to turn it off, or `pages: false` to write only `llms.txt`. Raw HTML is left out of the copies unless `build.unsafeHTML` is on.
