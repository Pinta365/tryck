description: Image sizes and lazy loading for Markdown images.
---

- **Image sizes.** Markdown images get `width` and `height` read from the image file, so the browser reserves their space and text below an image no longer jumps while it loads. This works for PNG, JPEG, GIF and WebP images in `content/` or `static/`.
- **Lazy loading.** Markdown images get `loading="lazy"`, so images further down the page load only when the reader scrolls near them.

See [Images](../02-writing/03-links.md#images). `defaults.imageAttributes: false` turns both off.

Upgrading: `<img>` tags from Markdown now carry `width`, `height` and `loading` attributes. The built-in theme's stylesheet adds `height: auto` to images so they keep their aspect ratio when scaled down; if you use your own theme, add `img { max-width: 100%; height: auto; }` to it, or set `defaults.imageAttributes: false`.
