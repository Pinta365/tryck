Four things readers expect on a docs page, in the built-in theme:

- **Copy buttons** on code blocks copy the code without line numbers.
- **Heading anchors**: a `#` next to every heading below the page title links to that section. `defaults.headingAnchors: false` turns them off.
- **Edit this page**: `theme.editUrl` adds a link to each page's source file in your repository, including pages of older versions.
- **Last updated**: with `build.lastUpdated: true`, pages show the date of the last commit that changed their file, read from git. The sitemap uses it as `lastmod` for pages without a `date`.

See [Page extras](../04-themes/01-built-in-theme.md#page-extras).

Upgrading: heading anchors are on by default, so headings in the HTML now end with an `<a class="heading-anchor">`. For "Last updated" dates in CI, check out the full history (`fetch-depth: 0` on GitHub Actions). Plugins and templates see `LastUpdated` on pages, and templates get `.EditURL`.
