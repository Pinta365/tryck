The built-in theme has a search box. It opens with the **Search** button, `/` or Ctrl+K, and searches titles, headings and text in the browser, ignoring case and accents, with no server or external service. Results link straight to the matching section. See [search](../05-extending/01-built-in-plugins.md#search).

Upgrading: in `/search-index.json`, `headings` are now objects, `{id, text}`, instead of strings. Custom headers can include the box with `{{ partial "search" . }}`.
