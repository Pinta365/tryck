**Custom directives from templates.** A file in `layouts/directives/` adds a `:::` directive, with no code. See [Custom directives](../05-extending/02-custom-directives.md).

**JavaScript plugins.** A `.js` file in `plugins/` is a plugin, run by the stock binary with nothing to install. See [Script plugins](../05-extending/03-script-plugins.md).

**Also new:**

- Tabs can be nested, and bare attributes such as `{open}` work. Attributes that cannot be parsed give a `directive.attrs` warning instead of disappearing.
- `partials/head-end.html` and `partials/body-end.html` add analytics or scripts to every page without copying a layout.
- A site's `theme.css` stylesheets are added after a theme folder's instead of replacing them.
- This documentation site, built with tryck.

Upgrading: building from source now needs Go 1.26 or later. Release binaries are unaffected.
