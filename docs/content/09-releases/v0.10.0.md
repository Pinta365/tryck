- **llms.txt per version.** On a [versioned site](../02-writing/06-versioned-docs.md), each older version now gets its own `llms.txt`, Markdown copies and, with `full`, `llms-full.txt` under its URL: `/v1/llms.txt` next to the current `/llms.txt`. Its pages link it, so an agent reading v1 docs gets v1 Markdown. See [Versioned docs](../05-extending/01-built-in-plugins.md#versioned-docs) in the llmsTxt plugin.
- **Feed links in `<head>`.** Pages linked their feeds after the `head-end` partial, which should end `<head>`. The links now come right after the title.

Upgrading: versioned sites now write the llms.txt files for older versions too. Set `plugins.llmsTxt.versions: false` to keep them to the current version.
