**Installing**

- **Homebrew and Scoop.** `brew install pinta365/tap/tryck` on macOS, and on Windows `scoop bucket add pinta365 https://github.com/Pinta365/scoop-bucket` followed by `scoop install tryck`. Both are updated with every release. See [Installation](../01-getting-started/01-installation.md).
- **Intel Macs.** Releases include `tryck_darwin_amd64.tar.gz` again, next to the Apple silicon build.

**Accessibility**

- **Share image descriptions.** The `social` plugin's `imageAlt` option, and `imageAlt` front matter next to a page's own `image`, describe the share image for screen readers (`og:image:alt`, `twitter:image:alt`). See [social](../05-extending/01-built-in-plugins.md#social).
- **Images without alt text** get an `image.alt` note with `--verbose`, so you can find images screen readers skip. It is a note, not a warning, since an empty alt text also marks a decorative image.

Upgrading: nothing to change. If you installed tryck by hand, you can switch to Homebrew or Scoop to get updates with the rest of your tools.
