The built-in theme was checked with axe against WCAG 2.2 AA, in light and dark mode, and every finding is fixed:

- The search button has an accessible name on narrow screens, where only its icon shows.
- Search results are proper listbox options, and marked matches keep readable contrast.
- Code blocks that scroll sideways can be scrolled with the keyboard.
- The draft and old-version banners are labelled page regions.
- Line numbers in code blocks use the theme's `--muted` colour, since some highlighting themes make them too faint.

Pages no longer shift while loading: the search button and the first tab are in place before the scripts run. Printed pages leave out the header, navigation and search, show every tab with its label, and wrap long code lines. See [Accessibility and print](../04-themes/01-built-in-theme.md#accessibility-and-print).

Upgrading: nothing to change. A custom layout that copied `baseof.html` keeps working; copy it again to get the fixes.
